# Agent notes

## User-facing copy

- Never use the word "row" in user-facing language. It names the UI's
  furniture, not anything the reader cares about; say what the thing is —
  the pollutant, the number, the line — or restructure the sentence.
  ("The numbers above are the model's own averages", never "the rows
  above".) Code identifiers and comments are fine.
- Windows are written "24h" / "8h" / "1h", never "24-h" or "8-h", and an
  averaged figure says "avg" in labels ("8h avg"), "average" in prose —
  never "mean".
